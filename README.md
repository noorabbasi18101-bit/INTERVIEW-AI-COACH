# 🎯 AI Interview Coach

AI-powered interview preparation platform that helps students, fresh graduates, interns, and job seekers practice interviews in a realistic, personalized environment.

Many people struggle with interview prep due to lack of personalized feedback and realistic practice. *AI Interview Coach* solves this by generating tailored interview questions based on field, interview type, and difficulty level — then delivering AI-powered feedback and performance analysis.

*Target Users:* Students · Fresh Graduates · Internship Applicants · Job Seekers

---

## 🌐 Live Application
*Live URL:*  https://interview-ai-coach-gray.vercel.app/

---

## 🚀 Features

*AI-Powered Practice*
- Generates interview questions using Gemini AI
- Creates fully personalized interview sessions

*Difficulty Levels*
| Level | Questions |
|---|---|
| Beginner | 5 |
| Intermediate | 8 |
| Advanced | 10 |

*Interview Types*
Technical · Internship · Job Interview

*Fields Supported*
Computer Science · Business · Marketing · Medical · Engineering · Other (General)

*AI Feedback System*
- Reviews responses objectively
- Highlights strengths & weaknesses
- Gives constructive, personalized feedback

*Result Dashboard*
- Overall score & performance summary
- Strengths and areas for improvement

*Deep Analysis*
- Detailed answer evaluation
- Communication & confidence assessment
- Personalized improvement suggestions

*Practice Again*
- Generates a fresh session, avoiding repeated questions

*Responsive Design*
- Mobile-first, works across all screen sizes

---

## 🤖 AI Feature

Powered by *Google Gemini AI*, the app:
1. Generates interview questions based on field, type, and difficulty
2. Analyzes user responses
3. Produces scores, feedback, strengths, weaknesses, and improvement tips

*System Prompt Guidelines* — the AI is instructed to:
- Generate relevant, field-matched questions
- Adjust difficulty per selected level
- Avoid repetitive questions
- Analyze responses objectively
- Provide constructive, realistic feedback

## ⚙️ Getting Started

```bash
# Clone the repository
git clone   https://github.com/noorabbasi18101-bit/INTERVIEW-AI-COACH.git
cd ai-interview-coach

# Install dependencies
npm install

# Configure environment variables
# Create a .env file:
GEMINI_API_KEY=YOUR_GEMINI_API_KEY

# Run development server
npm run dev

# Build for production
npm run build
